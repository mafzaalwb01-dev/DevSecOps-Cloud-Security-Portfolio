Welcome to my **DevSecOps & Cloud Security Engineering Roadmap**!

This repository documents my journey from Linux and networking fundamentals to cloud infrastructure, automation, DevSecOps security tools, and cybersecurity.

This is not just a roadmap. It is my learning journey, practical laboratory, and proof of work.
