# Step 7 — Final Troubleshooting

## 📚 What I Practiced

In this final practical, I combined the Linux commands I learned in the previous steps to troubleshoot a basic server problem.

### Commands Used

- `pwd` — Check current directory
- `whoami` — Check current user
- `df -h` — Check disk space
- `free -h` — Check memory
- `ps aux` — Check running processes
- `ss -tuln` — Check listening ports
- `ping` — Test network connectivity
- `ip addr` — Check network information
- `hostname` — Check server name
- `curl` — Test website connectivity

## 🧪 Final Troubleshooting Process

I practiced checking a Linux system step by step instead of using only one command.

### Troubleshooting Order

1. Check where I am
2. Check the current user
3. Check disk space
4. Check memory
5. Check running processes
6. Check network information
7. Check listening ports
8. Test network connectivity
9. Test website connectivity

## 🌍 Real-World Use

This type of troubleshooting can be used when a Linux server or application is not working correctly.

For example:

- Server is slow → check `free -h` and `ps aux`
- Disk is full → check `df -h`
- Website is not responding → check `ss -tuln` and `curl`
- Network problem → check `ip addr` and `ping`
