# 01 — Server Basics

## 🎯 Objective

The goal of this section is to practice basic Linux commands used to identify and understand a Linux server.

As a beginner Cloud Engineer, these commands help me understand the basic information of a Linux cloud server or virtual machine.

---

## 🧪 Commands Practiced

| Command | Purpose |
|---|---|
| `pwd` | Shows the current working directory |
| `whoami` | Shows the current logged-in user |
| `hostname` | Shows the system/server hostname |
| `uname -a` | Shows detailed Linux system information |
| `uptime` | Shows how long the system has been running |
| `ls -la` | Lists files and directories, including hidden files |
