# 03 — Users and Permissions

## 🎯 Objective

In this section, I practiced basic Linux user information, file ownership and file permissions.

These skills are important for Linux server administration and Cloud Engineering because access to files and systems must be controlled properly.

---

## 🧪 Commands Practiced

| Command | Purpose |
|---|---|
| `whoami` | Shows the current user |
| `id` | Shows user and group information |
| `ls -l` | Shows file permissions and ownership |
| `chmod` | Changes file permissions |
| `chown` | Changes file ownership |

---

## 💻 Practical Task

I checked my current user and user ID, created a test file, checked its permissions, changed its permissions and verified the changes.

## ☁️ Cloud Engineering Connection

Users and permissions are important for securing Linux cloud servers.

A Cloud Engineer needs to understand:

- Which user is accessing the server
- Which groups a user belongs to
- Who owns a file
- Who can read, write or execute a file
- How to change file permissions safely
