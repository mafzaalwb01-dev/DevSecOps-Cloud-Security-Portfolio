# Step 4 — Processes & Services

## 📚 What I Practiced

In this practical, I learned how to check and monitor running processes in Linux.

### Commands Practiced

- `ps` — Shows running processes
- `ps aux` — Shows detailed information about running processes
- `grep` — Searches for a specific process
- `top` — Shows live process monitoring
- `jobs` — Shows background jobs
- `&` — Runs a command in the background
- `pkill` — Stops a process by its name

## 🧪 Practice

I created a practice environment and worked with Linux processes.

### What I Learned

- How to run a process in the background
