# Step 6 — Storage & Monitoring

## 📚 What I Practiced

In this practical, I learned how to check disk space, memory usage, and system resources in Linux.

### Commands Practiced

- `df -h` — Shows available and used disk space
- `du -sh` — Shows the size of a directory
- `free -h` — Shows RAM and swap memory usage
- `uptime` — Shows system running time and load
- `vmstat` — Shows system performance information

## 🧪 Practice

I practiced checking disk usage, directory size, memory usage, system uptime, and overall system performance.

### What I Learned

- How to check available disk space
- How to find the size of a directory
- How to check RAM and swap usage
- How to check system uptime
- How to monitor basic system performance

## 🌍 Real-World Use

These commands are useful for monitoring Linux servers and troubleshooting performance problems.

For example:

- `df -h` can help find a full disk
- `du -sh` can help find a large directory
- `free -h` can help check memory usage
- `uptime` can help check system load
- `vmstat` can help investigate system performance
