# Step 5 — Networking

## 📚 What I Practiced

In this practical, I learned basic Linux networking commands.

### Commands Practiced

- `ping` — Tests network connectivity
- `ip` — Shows and manages network information
- `ss` — Shows active network connections
- `hostname` — Shows the system hostname
- `nslookup` — Checks DNS information
- `curl` — Tests and communicates with URLs

## 🧪 Practice

I practiced checking network connectivity, network interfaces, active connections, hostname, DNS information, and website connectivity.

### What I Learned

- How to test whether a host is reachable
- How to check network interface information
- How to check active connections and listening ports
- How to check the system hostname
- How to check DNS information
- How to test a website from the terminal

## 🌍 Real-World Use

These commands are useful for troubleshooting network and server problems.

For example:

- `ping` can help check connectivity
- `ip` can help inspect network interfaces
- `ss` can help check listening ports and connections
- `nslookup` can help troubleshoot DNS problems
- `curl` can help test websites and APIs
