## LINUX NETWORKING COMMANDS

### 1. `ping`

`ping` is used to check whether a server, system, or network host is reachable and responding.

### 2. `netstat`

`netstat` is used to display network connections, listening ports, routing information, and network statistics.

> Note: `netstat` is a networking command, not a Network Interface Card (NIC).

### 3. `ifconfig`

`ifconfig` is used to view and configure network interfaces and IP addresses.

### 4. `traceroute` vs `tracepath`

Both commands are used to trace the path that network packets take from your system to a destination.

* `traceroute` → Shows the network path/hops to a destination.
* `tracepath` → Similar to traceroute and can also provide information about the path and MTU.

### 5. `mtr`

`mtr` combines features of `ping` and `traceroute` into one command.

It can continuously check connectivity and show the network path to a destination.

### 6. `nslookup`

`nslookup` is used to query DNS information and find the IP address associated with a domain name.

### 7. `telnet`

`telnet` can be used to test connectivity to a specific host and port.

### 8. `hostname`

`hostname` is used to display or set the hostname of the system.

### 9. `ip`

The `ip` command is used to view and manage network interfaces, IP addresses, routes, and other network information.

Example:

```bash
ip addr
```

### 10. `iwconfig`

`iwconfig` is used to view or configure wireless network interface information.

### 11. `ss`

`ss` is used to display network sockets, active connections, and listening ports.

### 12. `arp`

`arp` is used to view information about the ARP (Address Resolution Protocol) table, which maps IP addresses to MAC addresses.

### 13. `dig`

`dig` is used to query DNS servers and get detailed DNS information.

### 14. `nc (Netcat)`

`nc` or Netcat is a networking utility used for network connections, port testing, and transferring data.

### 15. `whois`

`whois` is used to find registration and ownership information about domains and IP addresses.

### 16. `ifplugstatus`

`ifplugstatus` is used to check whether a network interface has a physical network cable/link connected.

# EXTRA LINUX NETWORKING COMMANDS

### 1. `route`

The `route` command is used to view or manage the system's routing table.

### 2. `nmap`

`nmap` is used for network discovery and security auditing, such as discovering hosts and checking open ports on systems you are authorized to test.

### 3. `wget`

`wget` is a command-line utility used to download files from the internet.

### 4. `watch`

`watch` repeatedly runs a command and displays its output, which is useful for monitoring changes.

### 5. `iptables`

`iptables` is used to configure and manage firewall rules on Linux systems.

### 6. `traceroute`

`traceroute` is used to discover the network path and hops between your system and a destination.

### 7. `curl` vs `wget`

Both are command-line tools for working with network resources.

* `curl` → Commonly used for making requests, testing APIs, and transferring data.
* `wget` → Commonly used for downloading files and websites.

### 8. `jq`

`jq` is a command-line tool used to process, filter, and format JSON data.

# PRO COMMANDS
